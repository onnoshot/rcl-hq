# Data Imports

Kaynak videoları buraya bırak (veya scriptlere doğrudan tam dosya yolunu ver — data/imports/ üzerinden geçmesi zorunlu değil).

- Desteklenen format: ffmpeg'in okuyabildiği herhangi bir video (mp4, mov, mkv...)
- Beklenen kaynak yönü: yatay (16:9), ör. 3840x2160
- Büyük dosyalar burada birikirse, işlendikten sonra elle temizle — agent bu klasörü otomatik boşaltmaz
